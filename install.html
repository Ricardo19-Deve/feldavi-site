Install and set up Feldavi

About 30 minutes, once. After that your team sets up the app themselves with a QR code.

Before you start

  • Salesforce Enterprise, Unlimited, Performance or Developer Edition (Professional Edition with API access).
  • A System Administrator user to install the package.
  • Reps need an iPhone or iPad with iOS 17 or later.

  1. Install the Feldavi package

    Adds the Feldavi Setup console, the mobile configuration API and the Feldavi Admin and Feldavi User permission sets. Install in a sandbox first if your company requires it.

    Package release in progress. The installation links will appear here, and Feldavi will be listed on Salesforce AppExchange. For early access, email support@feldavi.com.
    Install in Production Install in Sandbox

  2. Assign permission sets

    Feldavi Admin to the people who configure the app, and Feldavi User to every rep who uses it. Reps keep their own Salesforce profile and sharing.

  3. Create the app connection

    In Setup, open External Client App Manager and create an app with OAuth enabled:

    • Callback URL: feldavi://oauth/callback
    • OAuth scopes: Manage user data via APIs (api) and Perform requests at any time (refresh_token, offline_access)
    • Turn on PKCE and turn off Require secret for Web Server Flow. No client secret is used.

    Copy the consumer key and paste it in Feldavi Setup → Workspace → Salesforce sign-in.

  4. Configure the workspace

    In Feldavi Setup, set your company name and brand colour, then choose which objects appear and which fields are hidden, read only or editable. Optionally connect an AI provider; its key stays in Salesforce.

  5. Share the setup QR code

    In Device setup, download the QR code or copy the link and send it to your team. Reps install Feldavi from the App Store, scan the code and sign in with their own Salesforce user.

Pricing

Feldavi Pro is a per-user subscription, monthly or yearly, bought in the app through the App Store. Prices are shown in the App Store in each country's currency. The Salesforce package is free.

Security review

Feldavi has no servers: the app talks only to your Salesforce org, with each user's own permissions. See Privacy & Security for the data flows and on-device protection.
